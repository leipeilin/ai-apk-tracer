## 1. 评审结论摘要

方案方向正确、锚点大体准确，T2.5a 前置项全部承接。但"复用 _invoke_prompt 状态机"声明与代码事实三处实质冲突：**R-1** run 级 AI 预算计费在 orchestrator（`_budgeted_ai_call`）而非 `_invoke_prompt`——explorer 直调将绕过 max_requests_per_run；**R-2** RepairInput.target_output_model Literal 无 "ExplorerObservation"——repair 环节必然 schema_invalid（顺带发现 DeepDive/Verify 同隐患）；**R-3** cache 判据（analysis_complete/evidence_refs）对 Observation 恒 no-op。修订后实施。
