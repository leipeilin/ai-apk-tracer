- 无 `ai_` 前缀注册策略正确：`_expected_schema_bytes` 遍历全部 AI_SCHEMA_MODELS、`_expected_registry_bytes` 仅校验 registry 声明项（sync-ai-protocol.py L44-48/L51-99），未注册 key 无强校验。
- `kind` 含 `other` 与 `ComponentSummary` 一致，兜底合理；`entry_method` 归一到 `entry_method_id`（maxLength 2048）兼容。
- `candidate_id` pattern `^expl_[0-9a-f]{20}$` 与 `expl_<20hex>` 完全一致。
- 复用 `ChainProposal` 避免重复定义；`other` 归一化风险与回退已显式列出。
- A-1..A-6/A-8 与 N-1/N-2/N-4/N-5/N-6 均逻辑可判定、与底层约束吻合。
