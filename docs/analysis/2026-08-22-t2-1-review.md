## 6. schema 修订记录（R-3 处置，T0.4 回归流程）

- `receiver_registrations.schema.json`：`receiver_class` 类型 `string` → `["string", "null"]`（required 保持——记录必须携带该键但允许 null）；
- 理由：`receiver_class_name` 对 opaque 注册点（工厂方法/复杂表达式）返回 None——按原 schema 一条即毒化整产物；
- 回归：`test_rule_artifacts.py` 补 receiver_class=None 用例（schema 校验通过）；既有 sample 用例不受影响（additionalProperties 宽松）。
